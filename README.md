# Coffee

Небольшая утилита для macOS, которая имитирует активность пользователя и не дает системе уйти в режим сна из-за бездействия.

> **Только macOS.** Проект использует системные API macOS (CoreGraphics) и не предназначен для других платформ.

## Как это работает

Скрипт каждые 30 секунд проверяет время бездействия через CoreGraphics. Если пользователь не трогал мышь и клавиатуру дольше 2.5 минут, выполняется минимальное движение курсора и нажатие клавиши `F15`.

## Требования

- macOS (обязательно)
- Python 3.14+
- [uv](https://docs.astral.sh/uv/)

## Установка

```bash
git clone git@github.com:prosvirnin-dev/coffee.git
cd coffee
uv tool install .
```

Команда `coffee` появится в `~/.local/bin`. Убедитесь, что эта папка есть в `PATH` (у uv обычно уже настроено). Удаление — `uv tool uninstall coffee`.

## Запуск

```bash
coffee
```

Терминалу нужно разрешение «Универсальный доступ» (Системные настройки → Конфиденциальность и безопасность), иначе macOS молча отбрасывает имитированные события. Остановка — `Ctrl+C`.

## Настройка

Параметры — поля класса `Coffee` в `src/coffee/__init__.py`:

| Параметр | Значение по умолчанию | Описание |
|---|---|---|
| `threshold` | 150 | Порог бездействия в секундах |
| `interval` | 30 | Интервал проверки в секундах |

## Логи

Уровень задает переменная окружения `COFFEE_LOG_LEVEL` (по умолчанию `INFO`).

```bash
git config commit.template .gitmessage
```
